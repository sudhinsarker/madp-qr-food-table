# Release notes

## 0.3.0 · Changes, extra orders and payment
- #1 Add, change and remove menu items: Built searchable menu management with validated add and edit forms, availability controls and removal confirmation.
- #2 Manage the table list: Built table creation, renaming, seating validation and removal that blocks tables with unpaid orders.
- #3 Get a QR code for each table: Built table-specific scannable QR generation, SVG downloads and direct menu links synchronized to the selected table.
- #4 Scan the QR code and browse the menu: Built table-bound menu browsing with category filters, dish quantities and an account-free basket review.
- #5 Build pipeline and preview environment: Prepared public settings from the root product identity and preserved the host-managed build, relative preview paths and scoped browser storage.
- #6 Staff sign-in and roles: Built local team sign-in, staff order access, owner and manager administration guards and a permission-denied recovery screen.
- #7 Place an order without an account: Built account-free first order submission and table-linked order confirmation with acceptance pending and persistent records.
- #8 Order within 2 minutes of scanning: Polished the three-step account-free ordering journey with instant local screens, accessible touch targets and feedback that leaves the bottom action clear.
- #9 See and accept incoming orders: Finished acceptance-gated preparation, dish-specific replacement selection, served status and explicit staff payment confirmation.
- #10 Live order updates for staff: Built same-browser live order updates, preserved independent table changes, guarded stale payment totals and matched the stacked tablet workspace.
- #11 Agree a replacement and update the order: Built the staff order workspace with unavailable dishes, explicit customer agreement and saved replacement previews.
- #12 Add extra items to the existing order: Built table order tracking and extra item review with extras joined to the existing order awaiting separate acceptance.
- #13 Choose to pay staff or pay on the phone: Built payment method selection and staff payment instructions while keeping the order unpaid until staff confirm receipt.
- #14 Phone payment provider connection: Built phone payment unavailability and retry recovery without taking card details; live payment completion requires a confirmed provider and server integration.
- #15 Security review of payments and order data: Reviewed payment and table data handling, added role helpers and documented the server authorization boundary of browser-local records.
